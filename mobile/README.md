# Horizon 28 Mobile

Expo React Native iPhone app for the Horizon 28 executive intelligence feed.

## Run In iOS Simulator

```bash
cd mobile
npm run ios
```

This starts Expo and opens the app in the iOS Simulator. If Expo starts without opening the simulator, press `i` in the Expo terminal.

## Run In Expo Go

```bash
cd mobile
npm start
```

Open Expo Go on your iPhone and scan the QR code from the terminal. Keep the phone and Mac on the same network.

## Checks

```bash
npm run typecheck
```

## App Shape

- Dark-mode only iPhone interface
- Brief / Scenarios / Radar tabs
- Executive intelligence feed
- 2028 scenario projections
- Compute and export-control radar
- Action queue for board-level decisions
